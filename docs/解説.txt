アプリの概要および仕様解説

■ 1. 概要
本アプリケーションは、システムから提示されるテーマ（お題）に対して、2名のユーザーがそれぞれ異なる立場（選択肢）に分かれ、テキストチャット形式で議論（ディベート）を行うリアルタイム対戦アプリケーションである。

■ 2. 主要機能およびゲームフロー
・マッチングとテーマ選択
  ユーザー同士がマッチングされ、ランダムなお題が提供される。各プレイヤーは自身の主張する立場を選び、双方が異なる立場になった時点でゲームが進行する。

・ディベート（チャットフェーズ）
  制限時間およびカウントダウンタイマーが設けられた環境下で、テキストによる議論を行う。メッセージはデータベースとリアルタイムで同期される。

・終了とAI判定機能
  制限時間の終了、または両プレイヤーが任意のタイミングで「判定に進む（降参・判定ボタン）」を選択するとゲームが終了する。
  終了時点でデータベースのトリガーが機能し、Supabase Edge Functions を介して Google Gemini API へリクエストが送信される。AIは「お題」「双方の対象」「全チャットログ」を入力として読み込み、客観的な勝者（AまたはB）と判定理由を出力する。

・ユーザー戦績（ランキング）
  AIの勝敗判定を元にユーザーのトロフィー（レート）が増減し、成績に応じたランキングデータが更新される。

■ 3. システムアーキテクチャ
・フロントエンド: Flutter (Dart) を使用し、MVVMアーキテクチャに準拠。状態管理は Riverpod（HooksRiverpod）を利用。
・バックエンド: Supabase (PostgreSQL) を採用。リアルタイム通信機能を用いてチャットやフラグの同期を行っている。
・インフラ・処理ロジック:
  アプリ（フロントエンド）から直接勝敗の計算や外部API呼び出しは行わない。
  データ不整合やチートを防止するため、更新や状態確定のロジックはデータベース内のトリガーやストアドプロシージャ（RPC）に集約している。AI判定の実行も、DBトリガーから `pg_net` を用いて直接 Edge Function（Geminiエンドポイント）へWebhookを送信する設計を採用している。
