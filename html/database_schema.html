データベース構成図 (DM & オープンチャット)

ダイレクトメッセージ（1対1）とオープンチャット（多対多・グループ）のデータベース設計の比較資料です。両者とも基本構成は似ていますが、メタデータの有無や権限管理の仕組みに違いがあります。

1. ダイレクトメッセージ (DM) のデータベース構成

1対1のプライベートなやり取りを前提としたシンプルな構成です。ルーム自体には名前やアイコンがなく、属しているメンバーによって定義されます。

dm_rooms テーブル

DMのルーム（会話のスレッド）を管理するテーブル。2人のユーザー間の会話をまとめる箱の役割。

カラム名型制約・属性説明
iduuidPRIMARY KEYルームの一意のID
created_attimestamptzNOT NULL, DEFAULT now()作成日時

dm_room_members テーブル

誰がどのDMルームに参加しているかを管理する中間テーブル。通常、1つのルームに対して2行（自分と相手）が存在します。

カラム名型制約・属性説明
room_iduuidPRIMARY KEY, FK (dm_rooms.id)ルームID
user_iduuidPRIMARY KEY, FK (users.id)ユーザーID
created_attimestamptzNOT NULL, DEFAULT now()参加日時

dm_messages テーブル

DMルーム内で送信されたメッセージを保存するテーブル。未読・既読の管理機能（is_read）が含まれています。

カラム名型制約・属性説明
iduuidPRIMARY KEYメッセージの一意のID
room_iduuidFK (dm_rooms.id)紐づくルームのID
sender_iduuidFK (users.id)送信者のユーザーID
contenttextNOT NULLメッセージ本文
created_attimestamptzNOT NULL, DEFAULT now()送信日時
is_readbooleanNOT NULL, DEFAULT false既読フラグ

2. オープンチャット のデータベース構成

不特定多数のユーザーが参加できるグループチャット機能です。ルーム自体に名前やアイコンがあり、管理者(admin)と一般メンバー(member)の権限の違いが存在します。

open_chat_rooms テーブル

オープンチャットのルームそのものを管理するテーブル。ルームのメタデータ（名前、説明、アイコン、所有者）を保持します。

カラム名型制約・属性説明
iduuidPRIMARY KEYルームの一意のID
nametextNOT NULLルーム名
descriptiontextルームの説明文
icon_urltextルームのアイコン画像URL
owner_iduuidNOT NULL, FK (users.id)ルームの所有者（作成者）のユーザーID
created_attimestamptzDEFAULT now()作成日時

open_chat_members テーブル

オープンチャットの参加メンバーを管理するテーブル。ロール（権限）の概念があり、管理者によるキック処理などが可能です。

カラム名型制約・属性説明
iduuidPRIMARY KEYメンバー登録の一意のID
room_iduuidNOT NULL, FK (open_chat_rooms.id)参加しているルームID
user_iduuidNOT NULL, FK (users.id)参加しているユーザーのID
roletextDEFAULT 'member', CHECK ('admin', 'member')権限（'admin' または 'member'）
joined_attimestamptzDEFAULT now()参加日時

※制約として UNIQUE(room_id, user_id) が設定されており、同じルームへの重複参加を防いでいます。

open_chat_messages テーブル

オープンチャット内で送信されたメッセージを保存するテーブル。DMのような個別未読管理（is_read）は各メッセージ行にはありません。

カラム名型制約・属性説明
iduuidPRIMARY KEYメッセージの一意のID
room_iduuidNOT NULL, FK (open_chat_rooms.id)紐づくルームのID
user_iduuidNOT NULL, FK (users.id)送信者のユーザーID
contenttextNOT NULLメッセージ本文
created_attimestamptzDEFAULT now()送信日時

3. DMとオープンチャットの主な違い

  • ルームのプロパティ: DMルーム（dm_rooms）は名前やアイコンを持ちませんが、オープンチャット（open_chat_rooms）は名前、説明、アイコン、所有者情報を持ちます。
  • 権限の概念: オープンチャット（open_chat_members）には role（admin/member）が存在し、管理者によるキック等が可能です。DMにはロールの概念はありません。
  • 既読管理: DMのメッセージ（dm_messages）には is_read フラグがあり、相手が読んだかどうかを追跡しますが、オープンチャットのメッセージテーブルにはありません。
  • プライマリキーの違い: DMのメンバーテーブル（dm_room_members）は (room_id, user_id) の複合主キーを使用していますが、オープンチャット（open_chat_members）は独自の id を主キーとし、(room_id, user_id) にUNIQUE制約をかけています。
