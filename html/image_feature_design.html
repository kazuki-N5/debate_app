画像送信機能の設計と実装プラン

掲示板（ポスト・返信）、オープンチャット、DM機能において画像送信を可能にするためのデータベースおよびアプリ側の設計書です。

重要: 以前と同様に、データベースに新しいカラムを追加するためのSQLコードをSupabaseのSQL Editorで実行していただく必要があります。

1. データベース（Supabase）の設計変更

各テーブルに画像URLを保存するためのカラムを追加します。

対象テーブル 追加カラム名 データ型 概要
bbs_posts image_urls TEXT[] (配列) ポストの画像（最大4枚まで）のURLリストを保存。
bbs_comments image_url TEXT 返信の画像（最大1枚）のURLを保存。
open_chat_messages image_url TEXT オプチャのメッセージ画像（最大1枚）のURLを保存。
dm_messages image_url TEXT DMのメッセージ画像（最大1枚）のURLを保存。

Storage (画像保存用バケット)

  • bbs_images: 掲示板のポストおよび返信の画像を保存するバケットを新設（または既存利用）。
  • chat_images: DMやオープンチャットのチャット画像を保存するバケットを新設（または既存利用）。

2. アプリ（Flutter）側の実装設計

2.1 掲示板ポスト（最大4枚）

  • UI実装: BbsPostCreatePage に画像選択アイコン（ImagePicker.pickMultiImageを使用）を配置し、選択された画像（最大4枚まで許可）のサムネイルを表示します。
  • 送信ロジック: ポスト作成時に選択された画像をSupabase Storageにアップロードし、取得したURLのリスト（List<String>）を bbs_posts の image_urls にインサートします。
  • 表示UI: BbsTimelinePage およびポスト詳細画面で、image_urls が存在する場合、1枚〜4枚に応じたグリッドレイアウト（Twitter風）で画像を表示します。

2.2 掲示板の返信（最大1枚）

  • UI実装: BbsCommentPage のコメント入力欄の横に画像アイコンを追加し、ImagePicker.pickImage で画像を1枚選択できるようにします。
  • 送信ロジック: コメント送信時、画像があればStorageにアップロードして image_url を bbs_comments にインサートします。
  • 表示UI: 返信一覧の各アイテム内で、テキストの下に画像を大きく表示します。

2.3 オープンチャット & DM（メッセージとして1枚送信）

  • UI実装: OpenChatRoomView および DmRoomPage の入力欄（TextField）の左側または右側に写真アイコン（📷）を追加します。
  • 送信ロジック:
    1. アイコンをタップして画像を選択。
    2. 選択直後に（テキストなしでも）またはテキストと一緒に送信ボタンを押した際に、画像をStorageにアップロード。
    3. 取得したURLを image_url として open_chat_messages / dm_messages にインサートします。
  • 表示UI: MessageBubble 内に画像表示領域を追加します。image_url がある場合、吹き出し内に角丸で画像を表示します。画像タップでフルスクリーン表示（Heroアニメーション等）できるとUXが向上します。

3. 実行するSQLコード（準備用）

-- bbs_posts テーブルに画像配列カラムを追加
ALTER TABLE public.bbs_posts ADD COLUMN IF NOT EXISTS image_urls TEXT[];

-- bbs_comments テーブルに画像カラムを追加
ALTER TABLE public.bbs_comments ADD COLUMN IF NOT EXISTS image_url TEXT;

-- open_chat_messages テーブルに画像カラムを追加
ALTER TABLE public.open_chat_messages ADD COLUMN IF NOT EXISTS image_url TEXT;

-- dm_messages テーブルに画像カラムを追加
ALTER TABLE public.dm_messages ADD COLUMN IF NOT EXISTS image_url TEXT;

-- ※ 掲示板一覧・返信一覧のRPC関数（get_bbs_posts_with_status等）を修正し、
-- 新しいカラムもSELECT結果に含めるように再定義します（実際の作業時にSQLを生成します）。

4. 実装の進め方

  1. Supabaseで上記のSQLを実行し、カラムを追加する。またStorageバケットを作成/確認する。
  2. Dartのモデル（BbsPost, BbsComment, OpenChatMessage, DmMessage）を更新し、新しいフィールドを追加する。
  3. Providerクラス（送信ロジック）を更新し、Storageへのアップロードとインサート処理を実装する。
  4. 各UI（作成画面、タイムライン画面、チャット画面）を更新し、画像選択ボタンと表示用のウィジェットを組み込む。
