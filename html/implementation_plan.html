コミュニティ「オープンチャット」機能 実装プラン（改訂版）

LINEのオープンチャットのように、管理者（指揮官）権限、アイコン設定、参加確認ダイアログを備えた本格的なチャット機能を実装します。

1. 追加・強化される機能

  • ルームのアイコン設定: ルーム作成時にアイコン画像を設定可能に。
  • 入室前ダイアログ: ルーム一覧からタップした際、アイコンや詳細情報を確認して「参加する」を選ぶダイアログを表示。
  • メンバー管理と管理者権限:
    • ルーム作成者は「管理者」となり、メンバーを削除（キック）できる権限を持つ。
    • チャット画面から「メンバー一覧」を開き、管理ができるようにする。

2. データベース設計（Supabase）

新たに3つのテーブル構成とし、権限管理やアイコン情報を追加します。

2-1. open_chat_rooms（ルーム管理）

  • id (uuid, primary key)
  • name (text) - ルーム名
  • description (text) - ルームの説明文
  • icon_url (text) - アイコン画像のURL NEW
  • owner_id (uuid, FK) - 管理者（指揮官）のユーザーID
  • created_at (timestamp)

2-2. open_chat_members（メンバー・権限管理）NEW

  • id (uuid, primary key)
  • room_id (uuid, FK) - ルームID
  • user_id (uuid, FK) - ユーザーID
  • role (text) - 'admin' (管理者) または 'member' (一般)
  • joined_at (timestamp)

2-3. open_chat_messages（メッセージ管理）

  • id (uuid, primary key)
  • room_id (uuid, FK)
  • user_id (uuid, FK)
  • content (text)
  • created_at (timestamp)

3. アプリ側の実装（Flutter）

3.1 オープンチャット作成画面 (CreateOpenChatView.dart)

  • ルーム名、説明文の入力に加え、アイコン画像を選択・アップロード（Supabase Storage等を利用）できるUI。

3.2 参加確認ダイアログ

  • 一覧でルームをタップした際、JoinOpenChatDialog を表示。
  • 未参加の場合は「参加する」ボタンを押し、open_chat_members に自分のデータを追加してからチャット画面へ遷移する。

3.3 チャット画面とメンバー管理 (OpenChatRoomView.dart & OpenChatMembersView.dart)

  • チャット画面の右上に「メンバー」ボタンを配置。
  • 自分が role == 'admin' の場合、メンバー一覧から特定のユーザーを「削除（キック）」できるボタンを表示。
  • キックされたユーザーは open_chat_members から削除され、チャットに入室できなくなる。
