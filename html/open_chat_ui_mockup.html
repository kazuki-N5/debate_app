ハッシュタグ動作テスト & プリセット

説明文の#タグ抽出をお試しください
Dart側でのハッシュタグ抽出正規表現

ユーザーが説明文に入力したテキストから、以下の正規表現でハッシュタグを自動抽出してDBの tags カラムに保存します。

final tagRegex = RegExp(r'#([^\s#]+)');
final tags = tagRegex.allMatches(description).map((m) => m.group(1)!).toSet().toList();

説明文からの自動タグ化

ユーザーは専用のタグ入力欄に縛られず、説明文に「#ディベート」「#初心者歓迎」と自然に書くだけで自動タグとして登録されます。

PostgreSQL tags 配列型

tags text[] DEFAULT '{}' により、GINインデックスを活用した爆速タグ検索が可能になります。

一覧・検索でのタグ絞り込み

オープンチャット一覧画面（OpenChatRoomsView）でもタグチップを表示し、ワンタップで検索可能に。

クリーンな青色AppBar

AppBarは鮮やかな青色（Colors.blue）で統一し、無駄な虫眼鏡や3点メニューを撤廃。

1. テーブルスキーマ変更 (`open_chat_rooms`)

open_chat_rooms テーブルに tags text[] DEFAULT '{}'::text[] カラムを追加し、GINインデックスを付与します。

-- 1. tags カラムの追加
ALTER TABLE public.open_chat_rooms
ADD COLUMN IF NOT EXISTS tags text[] DEFAULT '{}'::text[];

-- 2. タグ検索を高速化するGINインデックス
CREATE INDEX IF NOT EXISTS idx_open_chat_rooms_tags
ON public.open_chat_rooms USING gin (tags);

2. RPC関数 `create_open_chat_room` の改修

引数に p_tags text[] DEFAULT '{}'::text[] を追加し、登録時にタグを保存できるようにします。

CREATE OR REPLACE FUNCTION public.create_open_chat_room (
  p_name text,
  p_description text,
  p_icon_url text,
  p_background_url text DEFAULT NULL,
  p_password text DEFAULT NULL,
  p_tags text[] DEFAULT '{}'::text[]
)
RETURNS jsonb AS $$
DECLARE
  v_room_id UUID;
  v_user_id UUID := auth.uid();
BEGIN
  IF v_user_id IS NULL THEN
    RETURN jsonb_build_object('success', false, 'error', '認証されていません');
  END IF;

  -- ルーム作成 (tags カラムを含める)
  INSERT INTO open_chat_rooms (name, description, icon_url, background_url, password, owner_id, tags)
  VALUES (p_name, p_description, p_icon_url, p_background_url, p_password, v_user_id, p_tags)
  RETURNING id INTO v_room_id;

  -- 作成者を Admin として追加
  INSERT INTO open_chat_members (room_id, user_id, role)
  VALUES (v_room_id, v_user_id, 'admin');

  RETURN jsonb_build_object('success', true, 'room_id', v_room_id);
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

3. 一覧取得RPC `get_open_chat_rooms_with_status` のタグ検索対応

検索クエリ（p_search_query）で、名前・説明文に加えて tags 内のタグ一致も検索ヒットするように拡張します。また戻り値に tags text[] を含めます。

CREATE OR REPLACE FUNCTION public.get_open_chat_rooms_with_status(
  p_search_query text DEFAULT NULL
)
RETURNS TABLE (
  id uuid,
  name text,
  description text,
  icon_url text,
  background_url text,
  owner_id uuid,
  created_at timestamp with time zone,
  member_count bigint,
  is_joined boolean,
  tags text[]
) AS $$
...
WHERE
  (p_search_query IS NULL OR p_search_query = ''
    OR r.name ILIKE '%' || p_search_query || '%'
    OR r.description ILIKE '%' || p_search_query || '%'
    -- タグ完全一致 または タグ配列内に含むか検索
    OR p_search_query = ANY(r.tags)
    OR REPLACE(p_search_query, '#', '') = ANY(r.tags)
  )
...
$$ LANGUAGE plpgsql SECURITY DEFINER;
