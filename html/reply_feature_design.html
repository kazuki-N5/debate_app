リプライ機能 ＆ AI審査プロンプト構造化 設計書

ユーザーが特定の発言を長押しして「リプライ」を行い、会話の論理関係（どの主張に対する反論か）を明示できるようにします。
さらに、現在のAI（DeepSeek/Gemini）へのベタ書き会話送信を刷新し、リプライ関係を構造化したプロンプトを渡すことで、AIが正確に反論力（rebuttal）や論理性（logic）を判定できる設計を定義します。

最終更新: 2026年8月

1. 直感的なリプライUI

長押しメニューから「リプライ」を選択。入力欄上部に返信先プレビューが表示され、送信後は吹き出し内に引用ヘッダーが美しく表示されます。

2. AI論理ツリープロンプト

従来のフラットな時系列テキストから、[#3 (↩ #1への反論)] 形式の参照ツリー構造に変換。AIがピンポイント反論を正確に採点可能に。

3. 軽量・安全なDB設計

reply_to_id やスナップショットカラムを追加。元メッセージが削除されても壊れない耐障害性設計。

Edge Function (gemini_v2/index.ts) のプロンプト刷新仕様

`gemini_v2/index.ts` において、`messages` テーブルから id, sender_id, content, reply_to_id を取得し、発言番号（#1, #2...）のマッピングを作成してプロンプトを構築します。

supabase/functions/gemini_v2/index.ts (抜粋) TypeScript / Deno 
// 1. メッセージ取得（reply_to_id を含む）
const { data: messages, error: mError } = await supabase
  .from("messages")
  .select("id, sender_id, content, reply_to_id")
  .eq("room_id", room_id)
  .order("created_at", { ascending: true });

// 2. メッセージID -> 発言番号 (#1, #2...) のインデックス辞書を作成
const msgIndexMap = new Map<string, number>();
messages?.forEach((m, i) => msgIndexMap.set(m.id, i + 1));

// 3. リプライ関係を明示した論理ツリーログの構築
const formattedChat = messages?.map((m, index) => {
  const num = index + 1;
  const label = m.sender_id === room.player1_id ? "A" : "B";
  
  let replyInfo = "";
  if (m.reply_to_id && msgIndexMap.has(m.reply_to_id)) {
    const targetNum = msgIndexMap.get(m.reply_to_id);
    replyInfo = ` (↩ #${targetNum}への反論/応答)`;
  }
  
  return `[#${num}${replyInfo}] ${label}: ${m.content}`;
}).join("\n");

// 4. System Prompt に反論ツリー評価の明確な基準を追加

データベース設計 ＆ マイグレーションSQL

対戦メッセージ・オープンチャット・DMの各テーブルに共通のリプライ用カラムを追加します。

非破壊的変更 (Nullable)
reply_to_id (UUID, Nullable)

返信先メッセージのUUID。タップ時に返信先へジャンプ・ハイライトするために使用。

reply_to_content (TEXT, Nullable)

返信時の元テキスト（スナップショット）。元発言が後から削除された場合でも引用プレビューが壊れません。

reply_to_user_name (TEXT, Nullable)

返信先ユーザー名（スナップショット）。JOIN不要で高速に吹き出し内に「@論理王A」を描画可能。

supabase/migrations/20260839000000_add_reply_columns.sql PostgreSQL DDL 
-- 1. 対戦チャット (messages) へのリプライカラム追加
ALTER TABLE messages 
  ADD COLUMN IF NOT EXISTS reply_to_id UUID REFERENCES messages(id) ON DELETE SET NULL,
  ADD COLUMN IF NOT EXISTS reply_to_content TEXT,
  ADD COLUMN IF NOT EXISTS reply_to_user_name TEXT;

-- 2. オープンチャット (open_chat_messages) へのリプライカラム追加
ALTER TABLE open_chat_messages 
  ADD COLUMN IF NOT EXISTS reply_to_id UUID REFERENCES open_chat_messages(id) ON DELETE SET NULL,
  ADD COLUMN IF NOT EXISTS reply_to_content TEXT,
  ADD COLUMN IF NOT EXISTS reply_to_user_name TEXT;

-- 3. DM (dm_messages) へのリプライカラム追加
ALTER TABLE dm_messages 
  ADD COLUMN IF NOT EXISTS reply_to_id UUID REFERENCES dm_messages(id) ON DELETE SET NULL,
  ADD COLUMN IF NOT EXISTS reply_to_content TEXT,
  ADD COLUMN IF NOT EXISTS reply_to_user_name TEXT;

-- 高速検索用インデックス
CREATE INDEX IF NOT EXISTS idx_messages_reply_to_id ON messages(reply_to_id);
CREATE INDEX IF NOT EXISTS idx_open_chat_messages_reply_to_id ON open_chat_messages(reply_to_id);
CREATE INDEX IF NOT EXISTS idx_dm_messages_reply_to_id ON dm_messages(reply_to_id);

返信引用タップ時のスムーズジャンプ ＆ ハイライト実装仕様

ユーザーが吹き出し内の引用部分（返信先プレビュー）をタップした際、Flutterの標準API Scrollable.ensureVisible を用いて該当メッセージを画面中央（alignment: 0.5）へスムーズスクロールさせ、一時的にハイライトアニメーションを発火させます。
