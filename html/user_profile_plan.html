ユーザープロフィール機能の実装計画

履歴画面やコミュニティ画面、掲示板からユーザーのアイコンをタップした際に、該当ユーザーのプロフィールを表示し、これまでの掲示板への投稿などを確認できるようにする機能の実装計画です。

1. ユーザーレビューが必要な事項

IMPORTANT: データベースのカラム追加について

添付いただいた参考画像のようなUI（ヘッダー画像、自己紹介文、画像付きの投稿など）を完全に再現するためには、現在のデータベース（Supabase）のテーブル構造にいくつかカラムを追加する必要があります。

以下のカラムを users テーブルや bbs_posts テーブルに追加して良いか、ご確認をお願いします。

  • users テーブルに追加:
    • bio (text): 自己紹介文（例：「業者じゃないよ」）
    • header_url (text): ヘッダー背景画像のURL
  • bbs_posts テーブルに追加:
    • image_url (text): 投稿に添付された画像のURL（※現在テキスト投稿のみ対応しているため）

※もし今回はデータベースの変更を行わず、UIのみ構築してダミーデータ（固定の背景画像や自己紹介文）を表示するだけであれば、その旨お知らせください。

2. 提案する変更内容

画面遷移の実装

アイコンをタップした際に新しいプロフィール画面に遷移するように、以下のファイル内の CircleAvatar コンポーネントを GestureDetector や InkWell でラップし、画面遷移処理を追加します。

  • [MODIFY] lib/views/HistoryPage.dart
  • [MODIFY] lib/views/CommunityPage.dart
  • [MODIFY] lib/views/bbs/BbsTimelineView.dart
  • [MODIFY] lib/views/bbs/BbsPostDetailView.dart

プロフィール画面の新規作成

添付いただいたUIデザインに基づく、新しいプロフィール画面コンポーネントを作成します。

  • [NEW] lib/views/UserProfilePage.dart
    • ヘッダー部分: SliverAppBar または Stack を用いて、上部に背景画像、その下に被さるようにアバター画像を配置します。
    • プロフィール情報部分: ユーザー名、ユーザーID、自己紹介文を表示し、右側にメッセージやいいね等のアイコンボタンを配置します。
    • タブバー部分: DefaultTabController と TabBar を使用して、「投稿」「リプライ」「メディア」の3つのタブを作成します。
    • 投稿リスト部分: TabBarView の中に、特定のユーザーのBBS投稿一覧を表示するリストビューを作成します。

プロバイダーとモデルの修正・追加

特定のユーザーのBBS投稿一覧を取得するためのロジックと、ユーザー情報を取得するロジックを実装します。

  • [NEW] lib/provider/user_profile_provider.dart
    • 特定の userId を引数に取り、そのユーザーのプロフィール情報と、そのユーザーが投稿したBBSの投稿一覧を取得する Provider を作成します。
  • [MODIFY] lib/modes/users.dart
    • bio や header_url がデータベースに追加される場合、モデルクラスにプロパティを追加し、パース処理を更新します。
  • [MODIFY] lib/modes/bbs_post.dart
    • 画像付き投稿をサポートする場合、image_url プロパティを追加します。

3. 検証計画

手動検証

  1. 履歴画面、コミュニティ画面、BBS画面でアバターアイコンをタップし、該当ユーザーのプロフィール画面へ遷移することを確認する。
  2. プロフィール画面に、選択したユーザーの名前、ID、アバター画像が正しく表示されることを確認する。
  3. （カラムを追加した場合）自己紹介文とヘッダー画像が正しく表示されることを確認する。
  4. 「投稿」タブに、そのユーザーが過去に投稿したBBSの一覧が表示されることを確認する。
NOTE

上記の「データベースへのカラム追加」について、ご判断（追加する、もしくはUIのガワだけダミーで作成する）をお知らせください。問題なければこの計画で実装を進めます。
