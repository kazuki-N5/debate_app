実装・データ取得仕様の解説

1. 「返信」タブ（X/Twitter スタイル）の仕組み

  • 取得クエリ: parent_post_id IS NOT NULL かつ user_id = 対象ユーザー の投稿（リプライ）を取得。
  • 親投稿の結合: 各リプライの parent_post_id をキーにして親投稿（元ポスト）の情報（投稿者名・アバター・本文）を同時に取得。
  • UI構造: 上部に「親ポスト」、下部に「ユーザーの返信」を配置し、親アバターの下から返信アバターまで 縦の連結線（スレッドライン） を引いて表示します。

2. 「メディア」タブ（画像付きのみ抽出）の仕組み

  • 取得クエリ: user_id = 対象ユーザー かつ image_url IS NOT NULL AND image_url != '' の投稿（ポスト・返信問わず）を取得。
  • 表示形式: グリッド表示（または画像付きタイムライン形式）で一覧化。タップすると該当投稿の詳細へ遷移できます。
