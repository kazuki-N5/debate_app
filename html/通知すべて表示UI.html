🔔 通知一覧UI — 全タイプ表示

Debata のアプリ内通知（メッセージタブ > 通知）で表示される通知タイプを再現したHTMLモックです。
新仕様で通知タブに表示するのは7種 （like_post / like_comment / follow / reply_comment / comment / resba_apply（応募）／ resba添付（返信・コメント））と、 未読・既読・いいね集約・レスバ付きバッジ・引用ボックスなど全表示パターンを含みます。
※ DM・オプチャのレスバ添付（「レスバが届きました」）は通知タブに表示せず、メッセージタブ（DM/クラブ）で表示します。
配色・文言は lib/widgets/notification/notification_list_tile.dart と lib/views/MessagePage.dart の実コードに準拠。 resba_apply / resba添付 は新規追加予定のタイプ（モック表示のみ・実装未着手）。
